User Guide

When searching in Chaghatay, inputs in both Perso-Arabic script and Latin script are acceptable.

Since Perso-Arabic is an abjad, some vowels present in a word as spoken aloud are not represented in written form, while vowels that are present in written forms may correspond to multiple possible sounds.

For this reason, when searching with Latin script, the Dictionary accepts both verbatim, character-for-character Romanizations of the written Perso-Arabic word as well as full phonetic reconstructions of the word, should the searcher know what that is. For both verbatim transliterations and phonetic transcriptions diacritics are optional, although including them in search may help narrow down results.

For example, the word چمچلاق will be retrieved if the user searches for čmčlaq (verbatim), cmclaq (verbatim without diacritics), čimčilaq (phonetic), or cimcilaq (phonetic without diacritics).
